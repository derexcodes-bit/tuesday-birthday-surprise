# A Tuesday surprise for Daniella

A single-file birthday page. Personalize the recipient, your sign-off, and a private memory with **Make it personal**. Those details are saved only in the current browser.

## Open locally

Open `index.html` in a browser. The page uses a hosted Unsplash photo and Google Fonts, so those assets need an internet connection; the page itself is static and requires no server or build step.

The countdown is set for Tuesday, October 13, 2026. Update the target date in the inline script if reusing this page for another birthday.

## Publish

This is a static site and can be published with GitHub Pages. In the repository settings, enable Pages from the `main` branch and the root folder. Personalization is client-side and is not uploaded or shared with GitHub.
